# Character and novelty research

Initial research: 2026-07-30. Duplicate-search refresh: 2026-08-12.

## Selection criteria

The character had to be real and published, visually recognizable in a small
sprite, legally redistributable as an open-source derivative, absent from the
local Codex pet projects, and not discoverable as an existing public Codex pet.

## Selected character

Pepper is the young witch from David Revoy's webcomic Pepper&Carrot. The official
project publishes source files under CC BY 4.0 and provides a model sheet. This
permits adaptation and commercial redistribution with attribution, which avoids
the legal ambiguity common to fan projects based on proprietary anime.

Primary evidence:

- official model sheet:
  <https://www.peppercarrot.com/sb/viewer/sketchbook-src__2017-08-06_Pepper_s-model-sheet_by-David-Revoy.html>
- official licensing best practices:
  <https://www.peppercarrot.com/jb/documentation/120_License_best_practices.html>
- project philosophy and source access:
  <https://www.peppercarrot.com/en/about/index.html>

## Duplicate checks

The following exact or near-exact GitHub repository searches returned zero
repositories in the 2026-08-12 refresh:

- `"pepper carrot" codex pet`
- `"Pepper&Carrot" codex`
- `pepper-carrot codex pet`
- `pepper codex desktop pet`
- `codex pet anime`

GitHub code search also returned zero results for:

- `"pepper-carrot" "spriteVersionNumber"`
- `"Pepper&Carrot" "spriteVersionNumber"`
- `"Pepper | Pepper&Carrot"`

The current <https://codex-pet.com/> index exposed 617 gallery entries through
the text reader and contained no Pepper or Pepper&Carrot match. The
<https://www.codex-pet.org/> front page reported a larger catalog but its pet
list did not load through the reader, so it was not treated as affirmative
evidence in the refresh. Both galleries had also returned no manual match in
the initial 2026-07-30 pass.

The 2026-08-12 local inventory included 19 distinct peer project directories:
Baiyan, Chopper, Feibi Jiubi, Godette, Gold Ship, Haru Urara, Holo, Kagamine
Rin, two Kiki implementations, Megumin, Momo Ayase, Oguri Cap, an expressive
robot, Sakuya Izayoi, Scales, Takopi, Yueya Tuanzi, and Zundamon. Pepper does
not duplicate any selected character. Generic release controls such as CI,
validation, backup-first installation, and deterministic packaging are shared
engineering safeguards rather than novelty claims; this project's distinct
scope is the libre-webcomic character, attribution-checked source chain,
published generation prompts, and complete v2 visual-QA evidence.

These are reproducible search observations, not a claim that no private or
unindexed implementation can exist.

## Audience hypothesis

The project joins three existing audiences: Codex users, open-source desktop-pet
collectors, and the Pepper&Carrot free-culture community. Its shareable elements
are the recognizable licensed character, a one-click install link, an animated
preview, reproducible art QA, and a repairable installer. Stars and visits remain
an outcome to measure after publication, not a number this repository can
guarantee.
