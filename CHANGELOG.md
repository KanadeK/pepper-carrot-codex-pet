- Added Pepper as a complete Codex v2 animated pet.

- Refused symlinked or reparse-point pet targets and `pets` parent directories.
- Added deterministic release packaging and checksum generation.
- Added remote installers, automated tests, CI, release automation, and a live
  atlas preview.
